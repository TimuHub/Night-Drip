# Night Drip

**Pastel-goth визуальная новелла:** ночная кофейня, бариста, кот, диалоги и «сталкинг» в фейковом браузере — судьбы гостей и романтика через слова.

---

## Как играть и собирать APK (основной вариант)

Игра сделана на **Ren'Py** и собирается в **APK** для Android (HTML не используется для релиза).

1. **Установите Ren'Py:** https://www.renpy.org/latest.html  
2. **Откройте проект:** в лаунчере добавьте папку NightDrip (корень репозитория).  
3. **Запуск:** выберите проект → **Launch Project**.  
4. **Сборка APK:** **Build** → **Android** (при первом разе настроите SDK/NDK).

Подробно: [BUILD_APK.md](BUILD_APK.md)

## Структура проекта

- **`game/`** — всё содержимое игры Ren'Py:
  - `script.rpy` — основной сценарий
  - `characters.rpy` — персонажи и изображения (фоны, спрайты)
  - `screens.rpy` — экраны: телефон (босс), мини-игра кофе, браузер (сталкинг)
  - `gui.rpy` — стиль pastel-goth
  - `bg/`, `ch/` — фоны и спрайты (уже скопированы из `assets/`)
  - `data/` — структуры для персонажей и состояния кафе (JSON)
- **`assets/`** — исходные ассеты (дублируются в `game/bg`, `game/ch` для Ren'Py)
- **`ASSETS_NANA_BANANA.md`** — список эмоций/спрайтов и фонов для генерации (Nana Banana и др.)
- **`BUILD_APK.md`** — пошаговая сборка APK

## Концепт (кратко)

- **Одна смена** ≈ 10–15 мин; диалоги, выбор тона, доверие (trust).  
- **Сталкинг:** после смены — «браузер», ввод ключевого слова → одна «страница» с инсайтом; на следующей встрече — новые реплики. **Использовать знание в лоб — риск потери доверия и бэд-энда.**  
- **Кафе** меняется от решений (постеры, предметы, тени у окна).  
- **Атмосфера:** напряжение, кот (calm/alert/hiding), дождь — без морализаторства, мир «читается» по визуалу.  
- **Романтика** — через понимание человека и честные ответы, без фарма сердечек.

**Масштаб под контент:** десятки персонажей, сотни вариантов диалогов, страницы сталкинга, модификаторы кафе. См. [docs/CONCEPT_DEEP.md](docs/CONCEPT_DEEP.md), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/CONTENT_PIPELINE.md](docs/CONTENT_PIPELINE.md).

**Опыт игрока и TikTok:** [docs/PLAYER_AND_TIKTOK.md](docs/PLAYER_AND_TIKTOK.md). **Сборка APK:** [BUILD_APK.md](BUILD_APK.md). **Бесконечное расширение:** сюжет, персонажи, функции по версиям — [docs/EXTENDING.md](docs/EXTENDING.md). **Шрифт:** положи VT323-Regular.ttf в `game/gui/fonts/` и включи в `game/gui.rpy` (см. `game/gui/fonts/README.txt`).
