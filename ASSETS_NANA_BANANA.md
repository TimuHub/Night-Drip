# Night Drip — Ассеты для генерации (Nana Banana / др.)

Картинки генерируете отдельно и кладёте в `game/bg/` и `game/ch/`. Игра **не** на HTML — движок **Ren'Py**, сборка в **APK**.

## Фоны — вариации кафе (по флагам)

Один зал, но после решений игрока — изменения. Можно делать как **отдельные картинки** или как **оверлеи** (слои поверх базового фона):

| Имя | Описание |
|-----|----------|
| `cafe_poster_barista.png` | Постер «Ищем бариста» (после хорошего исхода студента) |
| `cafe_poster_artist.png` | Работа художника на стене |
| `cafe_empty_frame.png` | Пустая рама / сорванный постер (плохой исход) |
| `cafe_silhouette_window.png` | Тёмные силуэты у окна (мутная история) |
| `cafe_broken_mug.png` | Разбитая кружка (декоративный элемент) |

Формат: PNG с прозрачностью, чтобы класть поверх `cafe_day` / `cafe_night`.

## Браузер (сталкинг)

Экран «фейкового интернета» — это UI Ren'Py + картинки «страниц». Нужны **статичные скриншоты** (или арты) под ключевые слова:

- Соцсеть (профиль, пост)
- Отзыв / новость
- Переписка (чат)

Имена файлов можно привязать к ключам в коде, например: `browser_art_sophia.png`, `browser_work_leo.png`. Конкретный список — когда продумаете ветки сталкинга.

---

## Куда класть файлы

- **Фоны (BG):** `game/bg/` — JPG или PNG  
- **Персонажи (CH):** `game/ch/` — PNG с прозрачностью  
- **Оверлеи кафе:** `game/bg/` или `game/overlays/` (и прописать в `characters.rpy` / в сценах)

После добавления новых спрайтов нужно объявить их в `game/characters.rpy`, например:

```renpy
image sophia angry = "ch/sophia_angry.png"
image leo happy = "ch/leo_happy.png"
```
